## 02 — Variável

Variável é o primeiro tijolo de praticamente todo código que existe.

Pensa numa caixinha com nome: você guarda um valor dentro e usa quando precisar. É isso. Parece bobo agora, mas é a base de tudo que vem depois.

Salva esse post pra não esquecer e fica de olho na série, é um conceito por dia.

#programacao #aprenderprogramar #javascript #trilhadev #codigo #estudardev #logicadeprogramacao

## 03 — If / condição

Todo programa que existe toma decisão, e é o if que faz isso.

"Se a senha tá certa, entra. Senão, dá erro." Esse raciocínio de se isso, então aquilo é o coração da lógica de programação. Domina o if e metade do caminho tá andado.

Conceito 2 da série. Tem mais chegando todo dia.

## 04 — Loop

Programar não é escrever a mesma coisa mil vezes.

Loop faz o trabalho repetitivo no seu lugar: você escreve uma vez e o computador repete quantas vezes precisar. Esse é um dos conceitos que separa quem copia código de quem entende o que faz.

Conceito 3 da série, todo dia tem mais.

#programacao #aprenderprogramar #logicadeprogramacao #trilhadev #estudardev #codigo #devbr

## 05 — Função

Função é você dar um nome pra um pedaço de código e usar quantas vezes quiser.

Em vez de reescrever a mesma lógica em 10 lugares, você escreve uma função e chama ela. Menos código, menos erro, mais organização.

Conceito 4 da série.

## 06 — Tipos de dados

Antes de manipular dados, você precisa saber com o que tá lidando.

Texto, número, verdadeiro ou falso: cada tipo se comporta de um jeito. Misturar tipo errado é uma das maiores fontes de bug de iniciante.

Conceito 5 da série.

## 07 — Operadores

Todo if depende de uma comparação, e quem faz isso são os operadores.

Igual, maior, menor, diferente: eles devolvem verdadeiro ou falso e é isso que o seu código usa pra decidir o que fazer.

Conceito 6 da série.

## 08 — Array

Em vez de criar uma variável pra cada coisa, você junta tudo numa lista.

Array guarda vários valores em ordem e deixa você percorrer todos de uma vez (lembra do loop?). É a base de quase todo app que mostra uma lista de algo.

Conceito 7 da série.

## 09 — Undefined (erro comum)

Se você tá começando, já viu undefined aparecer do nada.

Não é bug do computador: é o jeito dele dizer "isso que você pediu não existe". Geralmente é um nome digitado errado ou um valor que você esqueceu de definir.

Salva esse pra quando bater o desespero.
