# TrilhaDev — gerador de prompt de VÍDEO (Gemini / Veo)

> Contexto pra IA. Quando eu pedir "gera vídeo sobre X" ou "post de vídeo",
> SIGA este arquivo. Saída = **prompt pronto pra colar no Gemini/Veo**, não código.

## O produto
TrilhaDev: app que ensina **programação do zero** pra iniciante brasileiro.
Estilo Duolingo (gamificado, leve, sem intimidar). Mascote: arara azul.
Objetivo do vídeo = atrair iniciante → seguir perfil → baixar app.

## Formato fixo
- **Vertical 9:16**, 1080x1920 (Reels / TikTok / Shorts).
- Duração: **8–15s** (Veo gera trechos curtos; se conceito grande, divide em cenas).
- Ritmo rápido, 1 ideia só. Tema mãe: **"1 conceito por dia"**.
- Texto na tela CURTO (mobile, lido em 1s). Português BR informal.

## Identidade visual (sempre no prompt)
- Cores: verde `#58cc02`, azul `#1cb0f6`, fundo escuro `#04090f`.
- Vibe: dark mode, glow neon suave, limpo, moderno, "tech aconchegante".
- Tipografia grande, sans-serif bold.
- Se couber: arara azul cartoon como elemento.

## Estrutura do vídeo (3 partes)
1. **HOOK (0–2s)**: pergunta/dor que prende. Ex "Seu código não roda?", "O que é uma variável?". Texto grande na tela.
2. **PAYOFF (2–10s)**: explica o conceito simples, 1 frase + visual (ex: snippet de código animado, analogia visual).
3. **CTA (10–15s)**: "Segue @trilhadev.ai pra aprender a programar" + logo + "Baixe na Play Store".

## Temas (rotacionar)
conceito JS · comando Git · boa prática código limpo · atalho VSCode · erro comum de
iniciante · lógica de programação · dica de carreira dev · termo técnico explicado simples ·
HTML/CSS · mentalidade pra aprender · "antes/depois" de código.

## O que ENTREGAR quando me pedirem
Para cada pedido, devolva nesta ordem:

### 1. Roteiro (PT-BR)
- Hook (texto na tela)
- Fala/legenda do meio
- CTA final

### 2. Prompt Veo/Gemini (EM INGLÊS — Veo entende melhor)
Um parágrafo descritivo cobrindo: aspect ratio 9:16, cena, movimento de câmera,
estilo visual (dark neon, cores da marca em hex), texto on-screen exato, mood, ritmo.
Modelo de prompt:
> "Vertical 9:16 short video, dark tech aesthetic, deep navy background (#04090f) with
> soft neon green (#58cc02) and blue (#1cb0f6) glow. [CENA]. On-screen text: '[TEXTO]'
> in bold white sans-serif. Smooth [movimento câmera]. Modern, clean, energetic, 10s.
> Style of a polished coding-education reel."

### 3. Legenda do post (caption)
2–4 linhas, voz humana informal BR + CTA + 7 hashtags PT incluindo #trilhadev.
**Sem emoji** (ou no máx 1). Emoji demais = cara de post de IA.

### 4. Áudio sugerido
Tipo de trilha/trend pra usar (ex: "som lo-fi tech", ou "áudio em alta no Reels").

## Regras
- Veo NÃO renderiza código real legível em closeup longo — descreva como "stylized code
  snippet" e ponha o código real como texto overlay (eu adiciono na edição).
- Nunca prometer "fica rico programando" / promessa falsa. Tom: realista + motivador.
- Se conceito não cabe em 15s → propor **série** (parte 1, 2, 3).
- Texto on-screen sempre curto o bastante pra ler no celular em 1–2s.
